# IOT-ML-Intrusion-Detection
Machine Learning-based Intrusion Detection System using the KDD dataset. Implements Decision Tree and Random Forest models to classify network traffic as normal or attack, achieving ~99.8% accuracy with feature importance analysis for cybersecurity insights.


# Intrusion Detection System (ML Project)

## 📌 Overview
This project detects network intrusions using Machine Learning.

## 📊 Dataset
- KDD Cup 99 Dataset
- Contains network traffic labeled as normal or attack

## ⚙️ Technologies Used
- Python
- Pandas
- Scikit-learn

## 🚀 Models Used
- Decision Tree
- Random Forest

## 📈 Results
- Accuracy: ~99.8%
- Feature Importance analyzed

## 📂 Files
- main.py → Main execution file
- preprocessing.py → Data cleaning & encoding
- KDDTrain+.txt → Dataset
